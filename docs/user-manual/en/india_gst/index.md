# India GST

> _Scaffolded stub — replace with proper documentation when this module is next touched._

Landing page for the `india_gst` module in the end-user manual. This
module adds GST (CGST/SGST/IGST) billing compliance for clinics
registered in India: GSTIN capture, place-of-supply-driven tax
calculation, SAC codes, credit notes, and a reconciliation report.
E-invoicing is scaffolding only in this release — no live GSP/IRP
provider is connected.
