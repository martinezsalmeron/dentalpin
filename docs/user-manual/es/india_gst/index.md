# GST India

> _Borrador generado automáticamente — sustituir por documentación completa la próxima vez que se toque este módulo._

Página de aterrizaje del módulo `india_gst` en el manual de usuario.
Este módulo añade cumplimiento GST (CGST/SGST/IGST) para clínicas
registradas en India: captura de GSTIN, cálculo de impuestos según el
lugar de suministro, códigos SAC, notas de crédito y un informe de
conciliación. El e-invoice es solo infraestructura en esta versión —
no hay un proveedor GSP/IRP real conectado.
